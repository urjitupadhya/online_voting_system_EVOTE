Evote App 🗳️

Evote is a blockchain-based voting system developed to ensure secure, transparent, and tamper-proof elections. It leverages the immutability of blockchain technology to provide fairness, trust, and efficiency in the voting process while enabling a seamless digital voting experience.

📌 Features

🔐 User Authentication – Secure login for voters

🗳️ Blockchain-based Voting – Ensures transparency & immutability

📊 Real-time Result Tracking – Instant result updates with blockchain validation

📱 Cross-platform Accessibility – Works on Android & Web

🎨 User-friendly Interface – Simple, intuitive design

🛡️ High Security – Eliminates risks of vote tampering & duplication

🛠️ Tech Stack

Frontend: Flutter, Dart
Backend: Django REST Framework
Database: Firebase
Blockchain: Ethereum / Solidity (Smart Contracts)
Tools/Platforms: Android Studio, Visual Studio Code

⚙️ System Requirements

Hardware: i5 or higher, 8GB RAM, 256GB+ storage

Software:

OS: Windows/macOS/Linux

Flutter & Dart SDK

Python (for Django backend)

Firebase CLI

Ganache / Hardhat (for blockchain testing)

🚀 Getting Started
Clone the Repository
git clone https://github.com/your-username/evote-app.git
cd evote-app

Backend Setup (Django + Blockchain)
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver

Frontend Setup (Flutter)
cd frontend
flutter pub get
flutter run
